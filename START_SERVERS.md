# Quick Start (Flask Only)

## Windows (Recommended)
1. Setup:
   - `scripts\setup.bat`
2. Run:
   - `scripts\run_backend.bat`
3. Open:
   - `http://localhost:5000/login`

## Manual (Any OS)
1. Install deps:
   - `python -m venv .venv`
   - `.\.venv\Scripts\python -m pip install -r requirements.txt` (Windows)
2. Run backend:
   - `.\.venv\Scripts\python server\app.py` (Windows)
3. Open:
   - `http://localhost:5000/login`
